# Damien Blaumüller – Portfolio

Persönliche Portfolio-Website, gebaut mit purem HTML, CSS und Vanilla JavaScript – ganz ohne Frameworks.

🔗 **Live:** [damienblaumueller.at](https://damienblaumueller.at)

## Über das Projekt

Diese Seite präsentiert meine Arbeit als Full-Stack Software Developer: Skills, Projekte, beruflichen Werdegang, Zertifikate und Kontaktmöglichkeiten – in einem dunklen, glasmorphen Design mit Blau-Violett-Farbverlauf.

## Features

- 🎨 Dark-Navy / Blue-Violet Glassmorphism-Design
- ✨ Scroll-Reveal-Animationen (IntersectionObserver)
- 📱 Vollständig responsive mit mobilem Dropdown-Menü
- 🧩 Modulare Sektionen: Über mich, Skills, Projekte, Werdegang, Zertifikate, Fakten, Kontakt
- 📬 Kontaktformular via [Formspree](https://formspree.io/) inkl. Honeypot-Spamschutz
- ♿ Fokus-sichtbare Zustände & `prefers-reduced-motion`-Support

## Tech Stack

| Bereich | Technologie |
|---|---|
| Struktur | HTML5 |
| Styling | CSS3 (Custom Properties, Grid, Flexbox) |
| Interaktivität | Vanilla JavaScript |
| Typografie | Space Grotesk, Inter |
| Formular-Backend | Formspree |

## Sektionen

1. **Hero** – Kurzvorstellung, CTA-Buttons, Kennzahlen
2. **Über mich** – Profilkarte, Standort/Ausbildung/Erfahrung, Zitat
3. **Skills** – Frontend, Backend, Datenbanken, Tools (mit Progress-Bars)
4. **Projekte** – Ausgewählte Arbeiten mit Links zu GitHub/Live-Demo
5. **Werdegang** – Timeline von Ausbildung bis heute
6. **Zertifikate** – Absolvierte & laufende Weiterbildungen
7. **Fakten** – Kennzahlen auf einen Blick
8. **Kontakt** – Formular + direkte Kontaktkanäle
