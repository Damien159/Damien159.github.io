JobTracker

JobTracker ist eine Web-App, mit der man seine Bewerbungen im Blick behält. Man trägt seine Bewerbungen ein und sieht auf einen Blick, wo man gerade steht gesendet, Antwort bekommen, Interview oder Absage. Das Backend läuft über eine ASP.NET Core API, das Frontend hab ich mit Blazor gebaut.
